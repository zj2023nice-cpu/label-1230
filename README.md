# 京东商城 - Vue 2 电商项目

## 项目介绍

这是一个基于Vue 2框架开发的功能完善、界面美观的电子商务网站,模仿京东商城的设计风格和核心功能。项目采用组件化开发模式,使用Element UI组件库,实现了响应式设计,适配不同设备屏幕。

## 技术栈

- **前端框架**: Vue 2.6.14
- **路由管理**: Vue Router 3.5.3
- **状态管理**: Vuex 3.6.2
- **UI组件库**: Element UI 2.15.13
- **HTTP请求**: Axios 0.27.2
- **数据模拟**: Mock.js 1.1.0
- **样式预处理**: Sass/SCSS
- **构建工具**: Vue CLI 5.0 / Webpack

## 项目特色

### 核心功能模块

1. **首页模块**
   - 轮播图展示主推商品
   - 8大分类导航入口
   - 热门商品推荐
   - 个性化商品推荐

2. **商品模块**
   - 商品列表页(分类浏览、排序、分页)
   - 商品详情页(图片展示、规格选择、购物车操作)

3. **购物车模块**
   - 购物车商品管理
   - 数量增减控制
   - 商品选择与批量操作
   - 实时价格计算

4. **用户模块**
   - 登录功能
   - 用户中心
   - 收货地址管理
   - 订单查看

5. **订单模块**
   - 订单确认
   - 支付流程(模拟)
   - 订单详情查看
   - 订单状态管理

### 技术亮点

- ✅ **组件化开发**: 模块化组件设计,代码复用性高
- ✅ **状态管理**: 使用Vuex进行全局状态管理,数据流清晰
- ✅ **路由守卫**: 实现登录验证和页面权限控制
- ✅ **Mock数据**: 使用Mock.js模拟后端接口,独立开发
- ✅ **本地存储**: 购物车和用户信息使用localStorage持久化
- ✅ **响应式设计**: 适配PC和移动端
- ✅ **美观UI**: 参考京东商城的设计风格,使用Element UI组件

## Mock数据说明

项目使用Mock.js模拟后端数据,包含:
- **64个商品**: 覆盖8大分类,每个分类8个商品
- **用户数据**: 演示用户信息和收货地址
- **订单数据**: 模拟订单记录和状态变化

所有数据仅存储在浏览器本地,刷新页面后Mock数据会重新生成。

## 注意事项
